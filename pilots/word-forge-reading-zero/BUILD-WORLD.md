# Growing owned workshop

Simon explicitly authorized icon-only action controls, complex-word machine
assembly, cumulative visible possessions, development and same-route publication.
Live baseline: v70 / 9f3dc1019be02b25e4b239221c080f3b3ad7a7f6.

All routine actions use SVG icons. Learning letters/words and optional Hebrew
meaning remain content; instructions remain accessible labels, not reading gates.
No speech instructions, new engine evidence, telemetry or media requests.
Existing nine embedded word/phoneme assets are preserved.

The workshop is a separate cosmetic collection. Four installed beginner
connections award one machine per basic round, idempotently. In thought, three
correct guided groups install three machine parts and a supported meaning match
installs the final rotor. This awards one owned machine per constructed attempt.
Replay, power, opening/closing, failed choices and unfinished attempts cannot
award another copy. Starting a new construction can add another machine.
The collection is not a measure of independent reading or calibrated mastery.

Every machine remains owned. Every second machine adds a robot, every third a
garden, every fourth a tower; six add an airship. The full workshop is available
through its landscape/map icon, with explicit zoom/pan and a return icon.
Past 120 machines, the detailed view shows the newest 120 while every owned
claim remains stored and the city milestones remain; maximum 10,000 claims.
These are original interactive vector assets, rather than new image downloads.

Dedicated local key: efn:wf-reading-zero:world:v1. Original pilot/legacy save
keys and schemas are untouched. Missing world data starts an empty collection;
earlier completed beginner rounds are imported once using the saved round number
(continue only follows completion); the active unfinished round is excluded.
An already built current beginner machine appears once on the next render.
Malformed/future data is preserved; writes are blocked. Stale-tab writes are
blocked instead of overwriting newer possessions. Denied storage runs temporarily
and uses a dashed preview plus warning/save icons. No silent destructive reset.
Complex reserved ids and awarded claim ids prevent duplicate reward on replay.

Tests cover idempotency/reload, unfinished attempts, stale tabs, corrupt/future
collections, denied storage and visible milestones. Existing full beginner loop
asserts that both completed rounds add exactly their own machine without changing
coins. Native browser completed six thought constructions with goal/replay audio,
0/1/2/3/4 installed parts, restored six owned machines, three robots, two gardens,
a tower and an airship, and silent reload. 320/360/640/720 no horizontal page
scroll; zoom scroll is contained inside the map. Physical phone, icon comprehension

## Whole-word challenge replaces guided thought assembly

The current complex challenge accepts neutral provisional part selections and
checks only an explicit whole-word submission. Exact thought completion awards
one cosmetic machine; prefixes, wrong submissions and edits do not. The former
three per-part checks and supported meaning-choice award gate are removed.
Meaning is a post-success explanation, with no semantic evidence claim.
Owned storage schema and all earlier claims remain unchanged. The new generated
environment is decorative atmosphere; background architecture is never counted
as owned. See THOUGHT.md and visuals/ART.md for current scope and provenance.
